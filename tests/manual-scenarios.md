# 학습 기능 안정화 검증 시나리오

작성: 2026-10-08. 원본 `reference/original-artifact.html`과 사용자 요청을 기준으로 작성했다. 이 문서는 검증 기준이며, 아래 시나리오를 실행했다는 뜻은 아니다. 실제 결과와 브라우저 증거는 별도 테스트 결과에 기록한다.

## 완료 및 보존 규칙

| 단계 | 완료 조건 | 이동·새로고침 때 보존할 값 |
|---|---|---|
| ① 어휘 | 글짓기 2개와 객관식 5개를 모두 입력하고 제출 | 원문 답안, 선택, 채점 결과, 잠금 상태 |
| ② 개념·인출 | 개념 읽기 활동 후 빈칸 5개와 확신도를 입력하고 제출 | 읽기/빈칸 하위 화면, 원문 답안, 확신도, 정오답 |
| ③ 읽기·진단 | 읽기 완료 → 핵심 문장 4개 제출 → 독해 7개 제출 | 읽기/핵심 선택/문제 하위 화면, 문장 선택, 독해 답안, 읽기 시간 |
| ④ 구조화·글쓰기 | 슬롯 1·2·2개를 배치해 제출하고 공백 제외 40자 이상 요약 제출 | 슬롯 위치, 미제출 요약, 첨삭 결과, 완료 상태 |
| 리포트 | 필요한 단계 결과가 모두 존재하고 집계에 성공 | 점수, 완료율, 소요 시간, 리포트, 동일 세션 기록 1건 |

- 정답률과 완료율은 별개다. 오답으로 제출해도 학습 완료 조건을 충족하며, 미응답은 완료로 세지 않는다.
- 뒤로 이동하거나 채점한 단계를 재방문해도 완료율은 내려가거나 중복 증가하지 않는다.
- 제출된 답안은 잠그거나 재채점을 요구해야 한다. 화면 답안과 저장된 결과가 서로 다른 상태를 허용하지 않는다.
- 진행 중 세션을 처음부터 시작할 때 확인 취소는 현재 세션을 유지한다. 확인 후 재시작해도 완료 기록은 보존한다.
- 오답/영역/전체 재학습은 새 세션 ID를 사용한다. 이전 기록은 변경하지 않는다. 부분 재학습의 대상과 점수 분모를 명확히 표시한다.
- 브라우저를 닫거나 숨긴 시간을 실제 학습 시간으로 무한 누적하지 않는다. 선택한 시간 계산 기준을 UI 또는 문서에 표시한다.

## 원본 정상 기능 회귀

- 어휘 카드 10개, 예문 강조, 글짓기 2개, 객관식 5개가 유지된다.
- 미응답 제출 안내가 유지되고, 어휘 1개 오답이면 객관식 결과는 4/5·80%다.
- 빈칸 정답과 허용된 표기 변형(예: `중심문장`, `바다`)은 기존대로 처리한다. 원문 답안은 정답 안내 텍스트와 별개로 보존한다.
- 확신도 `확실`+오답은 착각, `모름`+정답은 과소평가로 집계한다. `아마`의 지표 정의를 설명하고 자동으로 완벽한 자기평가로 오인하지 않도록 확인한다.
- 핵심 문장 3/4, 사실 5/5, 추론 1/2의 결과가 리포트에서 각각 유지된다.
- 독해 채점 후 정답/오답 스타일과 지문 근거가 표시되고, 재방문해도 근거가 중복 추가되지 않는다.
- 슬롯 문장 추가·빼기·재배치, 용량 제한, 동일 문장 중복 방지가 동작한다. 정확한 배치는 5/5다.
- 요약 39자 제출은 차단, 40자 제출은 허용한다. 공백·줄바꿈은 최소 글자 수에서 제외한다.
- 요약 낱말 포함 수/비율과 글자 수가 즉시 갱신되고, 제출 후 결과와 리포트가 일치한다.
- 첨삭은 외부 AI 호출 없이 규칙 기반으로 동작하며, 그 한계를 화면에 명시한다.

## 추가 경계 검증

1. **모든 하위 화면 복원:** 개념 읽기/빈칸, 읽기/핵심 문장/독해, 슬롯/작성/첨삭 이후 각각 새로고침한다. 채점 전 초안도 보존해야 한다.
2. **단계 잠금:** 초기 상태에서 ②~리포트에 진입할 수 없어야 한다. 완료 플래그만 있고 답안이 없는 복원 데이터도 잠금 우회로 인정하지 않는다.
3. **손상 데이터:** 문자열 `{`, `null`, `[]`, 부분 객체, 지원하지 않는 version/package, 잘못된 답안 인덱스, 중복 슬롯, 배열 대신 객체, 음수·과대 시간 값을 각각 검증한다.
4. **저장 실패:** localStorage 읽기/쓰기 예외·용량 초과가 나더라도 현재 학습은 가능해야 하고, 저장 실패를 숨기지 않아야 한다.
5. **부분 재학습:** 목표 영역까지 선행 학습 강제 없이 도착하되 목표 영역을 실제 제출해야 완료한다. 없는 오답에 대한 버튼은 이유를 안내하거나 비활성화한다.
6. **완료 후 불변성:** 제출된 입력·라디오·슬롯·요약을 재방문해 조작해도 기존 결과를 몰래 바꾸지 않는다. 라디오 레이블 클릭으로 선택 색만 바뀌는 현상도 없어야 한다.
7. **시간:** 새로고침 후 음수·NaN·Infinity가 없고, 리포트 재방문마다 완료 시간/총 시간이 늘어나지 않는다. 읽기 중 다른 단계로 이동하면 읽기 시간 처리 기준이 일관된다.
8. **동시 동작:** 연속 제출과 제출 직후 단계 이동/재시작을 실행해 오래된 비동기 결과가 새 세션에 들어가지 않는지 확인한다.
9. **출력 안전성:** 글짓기·요약에 `<b>문장</b>` 같은 문자를 넣어도 입력 내용이 임의 HTML로 실행되지 않고 텍스트로 보존된다.
10. **기록 재열람:** 진행 중 세션이 있는 상태에서 과거 기록을 읽어도 진행 세션을 덮어쓰지 않는다. 기록 상세의 답안·점수·재학습 경로가 해당 기록에 맞는다.
11. **화면 크기:** 모바일 390px, 태블릿 768px, 데스크톱 1280px에서 단계 메뉴·재개/확인 대화상자·리포트·기록·하단 버튼의 가로 넘침과 내용 가림을 확인한다.
12. **키보드:** Tab/Enter/Space로 주요 입력·메뉴·확인·재학습을 실행한다. 대화상자가 열리면 배경 학습 입력이 실수로 활성화되지 않아야 한다.

## 독립 계산용 정상 답안

- 어휘 선택(0부터): `[1, 2, 3, 0, 1]` → 5/5.
- 글짓기 예: `물이 마르고 소금이 굳었어요.`, `소금은 음식의 맛을 내는 역할을 해요.`
- 빈칸: `중심 문장`, `뒷받침 문장`, `바닷물`, `염전`, `증발` → 인출 5/5.
- 핵심 문장 인덱스(0부터): `[0, 3, 9, 13]` → 4/4.
- 독해 선택(0부터): `[1, 2, 1, 2, 1, 1, 1]` → 사실 5/5, 추론 2/2.
- 구조화 인덱스(0부터): `[[0], [3, 9], [13, 15]]` → 5/5.
- 요약 예: `소금은 음식의 맛을 내고 오래 보관하는 역할을 해요. 염전에서는 바닷물을 햇볕에 말려 물을 증발시켜 소금을 얻어요. 오래전 바다였던 땅속에서는 굳은 소금을 캐내요. 이렇게 여러 방법으로 소금을 생산해요.`

객관적 문항 정답률에 글짓기/요약의 규칙 기반 지표를 합산한다면 합산식과 분모를 별도로 기록한다. 실제 의미 이해를 평가하지 않는 낱말 포함 비율을 의미·표현 능력의 확정 점수로 표시하지 않는다.
