# 맞춤형 읽기 훈련

공개된 **소금은 어디에서 올까** Artifact의 지문과 문제를 유지하면서 저장·이어하기·결과·기록을 연결한 로컬 작업본입니다. 홈의 세 카드는 이제 서로 다른 영역별 활동으로 연결됩니다. 기존 통합 과정도 **전체 과정 학습하기**에서 계속 사용할 수 있습니다. 공개 Claude Artifact에는 변경 사항을 게시하지 않았습니다.

최신 화면은 토스 스타일을 참고한 `#F2F4F6` 회색 배경, 흰색 카드, `#191F28` 본문과 `#4E5968` 보조 문구를 사용합니다. 주요 동작은 `#1B64DA` 파랑으로 통일하고, 홈 진행 막대는 `#3182F6`을 사용합니다. 그라데이션과 카드 그림자가 없는 20px 둥근 카드 구성을 유지합니다. 유창성·어휘력·독해력 카드는 각각 옅은 Red·Mint·Blue 단색입니다. TDS 패키지를 도입하지 않았으며, 새 활동에 필요한 스타일만 `activity.css`로 확장합니다.

기본 흐름은 **홈 → 영역 선택 → 읽기·문제 풀이 → 결과 → 학습 기록 → 이어서 또는 다시 학습**입니다. 홈은 실제 저장 기록으로 누적 학습 시간, 오늘 완료한 영역, 최근 기록 3개를 표시합니다.

| 홈 훈련 카드 | 실제 활동 | 기본 채점 문항 수 |
|---|---|---:|
| 읽기 유창성 · Red | 글 읽고 빈칸 맞추기 → 빠르게 읽고 내용 맞추기 → 자동으로 표시되는 글 읽고 퀴즈 풀기. 각 활동 1회 | 3 |
| 어휘력 · Mint | 단어를 보고 뜻 맞추기 16문항 → 문장을 보고 단어 맞추기 16문항 | 32 |
| 독해력 · Blue | 글 읽기 1회 → 문단 순서 1문항 → 문단 구조 1문항 → 문단 내용 4문항 | 6 |

어휘의 고유 낱말은 기존 패키지의 **10개**입니다. 각 16문항의 마지막 6문항은 같은 낱말의 복습이며 화면에도 안내합니다. 어휘 오답은 다음 두 문항 이내 다시 나오고, 재시도에서도 틀리면 다시 복습합니다. 추가 복습은 기본 32문항과 별개이며 결과에서 **첫 풀이 정답률**과 **추가 오답 복습 결과**를 구분합니다.

빠르게 읽기는 60초 후 글이 닫히며 먼저 읽었으면 바로 문제로 넘어갈 수 있습니다. 자동 읽기는 시작 버튼을 누르면 기존 지문의 17문장이 각각 4초씩 표시됩니다. 일시 정지·계속 읽기를 지원하고 마지막 문장 뒤 퀴즈로 이동합니다.

기존 통합 과정은 **어휘 → 개념·인출 → 읽기·진단 → 구조화·글쓰기 → 리포트** 순서를 유지합니다. 기존 과정과 영역별 과정의 진행 중 답안은 별도로 저장합니다. 영역별 회차를 교체할 때는 확인을 받고, 완료 기록은 유지합니다. 홈은 두 종류의 기록을 합쳐 표시합니다. 오늘 완료는 한국 시간 기준이며 오답만 재학습한 회차는 영역 완료로 세지 않습니다. 이전 통합 과정의 기록은 기존 단계 대응 규칙에 따라 반영합니다.

## 실행

Python 3로 정적 서버를 실행합니다. 앱 실행에는 Node.js나 npm 설치가 필요하지 않습니다.

```sh
cd reading-training
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 [맞춤형 훈련 홈](http://127.0.0.1:4173/)을 엽니다. 진행 중 회차는 홈의 이어하기에서, 완료 회차는 이전 훈련 기록 또는 메뉴의 학습 리포트에서 확인합니다.

`dist/training.html`은 CSS 3개와 JavaScript 8개를 포함하는 단일 파일입니다. [단일 HTML 작업본](http://127.0.0.1:4173/dist/training.html)으로도 실행할 수 있습니다. 저장 동작이 브라우저마다 다른 `file://` 직접 실행보다는 HTTP 실행을 권장합니다. 두 경로는 같은 origin이므로 같은 저장소를 사용합니다. Google Fonts를 받지 못하면 시스템 글꼴로 표시됩니다.

## GitHub Pages

빌드는 같은 완성본을 `dist/index.html`에도 생성합니다. Pages에는 `dist`의 내용만 담은 `codex/github-pages` 브랜치의 루트(`/`)를 게시합니다. 원본 코드·테스트·문서는 기본 소스 브랜치에 보관합니다.

변경 후에는 테스트와 빌드를 실행하고 소스 커밋을 푸시한 다음, 다음 명령으로 배포 브랜치를 갱신합니다. 강제 푸시는 사용하지 않습니다.

```sh
git subtree push --prefix=dist origin codex/github-pages
```

로컬 주소와 GitHub Pages는 서로 다른 origin이므로 학습 기록과 진행 중 답안은 각각의 브라우저 저장소에 따로 저장됩니다. 로컬 기록은 자동으로 업로드되거나 이전되지 않습니다.

## 검증 및 단일 파일 생성

Node.js 22.12+ 또는 24+와 Python 3가 필요합니다. jsdom은 테스트 전용 의존성입니다.

```sh
npm ci
npm run check
npm test
npm run build
```

2026-10-08 기준 구문 검사, **전체 테스트 97/97**, 단일 HTML 빌드를 통과했습니다. 기존 회귀 46개와 기존 UI 통합 13개를 유지하고 콘텐츠 6개·영역별 엔진 19개·화면 통합 13개를 추가했습니다. 원본 `PKG`와 기준 파일 6개의 해시도 동일합니다. 실제 브라우저에서 세 영역 완료, 오답 재출제, 새로고침 후 선택 복원 및 390/820/1280px 화면의 가로 넘침 없음을 확인했습니다. 세부 증거와 검증 범위는 [영역별 활동 구현 보고서](ACTIVITY_FLOW_REPORT.md)를 참고하세요.

## 상태 및 저장 계약

- `trainingSession`: `version: 1`, `packageId: salt-v1`, 회차 ID, 단계·하위 화면, 마지막 입력 위치, 답안·확신도·문장 배치·요약, 제출 여부, 시간, 파생 결과.
- `trainingHistory`: 완료 회차 배열. 각 항목에 version·ID·완료 시각·시간·결과·세션 스냅샷을 저장합니다. 같은 ID는 중복 추가하지 않습니다.
- `areaTrainingSession.v1`: 영역별 `version: 1` 세션. 영역·활동 큐·현재 위치·선택/제출 답안·읽기 시간/위치·전체 시간·복습 원본 ID를 저장합니다.
- `areaTrainingHistory.v1`: 영역별 완료 세션 스냅샷. 기존 저장 키와 분리하며 같은 ID는 중복 추가하지 않습니다.
- 결과는 저장된 답안에서 다시 계산합니다. 제출된 답안은 잠그며 다시 풀기는 새 ID를 만듭니다.
- 입력과 이동 때 저장합니다. 기존 과정의 시간은 5초 간격, 새 영역별 과정은 학습 중 1초 간격으로 저장합니다. 이탈·숨김 이벤트에도 저장을 시도합니다. 갑작스러운 프로세스 종료는 마지막 시간 갱신 일부가 누락될 수 있습니다.
- 영역별 학습은 새로고침 후 선택 답안, 문단 순서, 제출 상태, 오답 재출제 큐, 읽기 시간과 자동 읽기 위치를 복원합니다. 자동 읽기는 계속 읽기를 눌러 재개합니다.
- 홈·리포트·기록·메뉴·재개 및 확인 대화상자, 숨겨진 탭의 시간은 학습 시간에 더하지 않습니다. 포인터 기반 읽기 지표는 시선 측정값이 아닙니다.
- 완료 기록 저장이 실패하면 새 회차로 덮어쓰지 않고 결과를 유지합니다. 저장 공간을 확보한 뒤 완료/재학습 동작을 다시 시도할 수 있습니다.
- 영역별 완료 기록은 200개까지 보관합니다. 한도를 넘으면 기존 기록을 삭제하지 않고 경고하며 현재 결과를 유지합니다. 손상된 영역별 완료 기록에도 새 기록을 덮어쓰지 않습니다. 기록 내보내기·한도 관리 화면은 아직 없습니다.
- 없음·깨진 JSON·부분 데이터·미지원 버전은 안내와 안전한 기본값으로 처리합니다. 지원하지 않는 원본 데이터를 영구 백업/마이그레이션하는 기능은 없습니다. 복구 후 새 진행 저장은 현재 키를 교체할 수 있습니다.

## 범위와 한계

고정된 한 개 지문과 기존 어휘 10개를 사용합니다. 어휘 32문항은 32개의 새로운 낱말을 의미하지 않습니다. 문단 순서·구조 문제는 기존 네 문단에서 구성했습니다. 낱말 포함·글자 수 등의 규칙을 실제 AI의 의미·문맥 평가로 표시하지 않습니다. 계정·서버 동기화·동시 탭 충돌 조정은 없고, 같은 브라우저 origin의 마지막 저장을 사용합니다. 브라우저 데이터 삭제 시 기록도 지워집니다.

표시된 사용자명과 학년은 현재 데모의 고정 정보이며 로그인이나 자동 레벨 산정 기능은 없습니다. 음성 인식·발음 평가·실제 시선 추적은 없습니다. 60초 및 문장당 4초는 고정값이며 학습자별 속도 설정은 없습니다.

첨부 어휘 CSV는 아직 실행 흐름에 연결하지 않았습니다. 이번 기능과 검증 경계는 [영역별 활동 구현 보고서](ACTIVITY_FLOW_REPORT.md), CSV 구조는 [CSV 자료 검토](CSV_DATA_NOTES.md)에 정리합니다. 과거 단계의 기록은 [Artifact 감사](ARTIFACT_AUDIT.md), [기능 안정화 결과](IMPLEMENTATION_REPORT.md), [리디자인 결과](REDESIGN_REPORT.md), [토스 스타일 결과](TOSS_THEME_REPORT.md)에 있습니다. 스타일 확장 시 [디자인 시스템](DESIGN_SYSTEM.md)을 참고하세요.
